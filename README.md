# Resume Assistant

Персональный сайт-резюме **Савельевой Любови Андреевны**, разработанный для вакансии **Ассистент**.

Сайт выполнен в формате адаптивного одностраничного приложения с удобной навигацией по разделам и автоматическим расчётом опыта работы.

---

## Возможности

- 📱 Адаптивная вёрстка для компьютеров, планшетов и мобильных устройств;
- 🍔 Мобильное меню (бургер-меню);
- 🧮 Автоматический расчёт:
  - общего опыта работы;
  - продолжительности каждого места работы;
- 🧭 Навигация между разделами страницы;
- 📄 Раздел «Обо мне»;
- 💼 Раздел «Опыт работы»;
- 🎓 Раздел «Образование»;
- 📚 Раздел «Курсы»;
- 📝 Раздел «Публикации»;
- 🛠️ Раздел «Навыки»;
- 💻 Раздел «Портфолио»;
- ℹ️ Раздел «Дополнительная информация».

---

## Используемые технологии

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Lyubov15/resume_assistant.git
cd resume_assistant
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск проекта

```bash
npm start
```

После запуска откройте в браузере адрес, который покажет Servor:

```text
http://localhost:8080
```
